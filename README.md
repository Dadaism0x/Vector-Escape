# Vector Escape

A minimalist 2D arcade game built with Unity. Dodge an endless stream of incoming obstacles for as long as you can — the longer you survive, the harder it gets.

---

## Gameplay

- **Click and hold** to thrust your ship toward the cursor
- Obstacles spawn from the edges of the screen and fly inward
- The spawn rate increases over time — there's no finish line
- Wrap around screen edges to escape tight situations
- Beat your high score

---

## Features

- Progressive difficulty: spawn interval shrinks continuously
- Random obstacle size and speed keep every run unpredictable
- Screen wrapping on all edges
- Persistent high score via `PlayerPrefs`
- Booster flame and explosion effect on death
- Responsive layout via `CameraScaler`

---

## Built With

- Unity 2D
- Unity Input System
- UI Toolkit

---

## Run Locally

1. Clone the repo
2. Open the project in Unity (2022.3 LTS or newer recommended)
3. Open the main scene in `Assets/Scenes/`
4. Press Play
